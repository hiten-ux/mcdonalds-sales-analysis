## 📌 Project Overview
Comprehensive sales intelligence report analyzing **12,097 orders** 
and **2,171 transactions** across categories, time windows, 
and product performance for a McDonald's restaurant operation.

## 🔍 Key Findings
| Metric | Value |
|--------|-------|
| Total Revenue | $11,453 |
| Total Orders | 2,171 |
| Top Category | Burger (40.3%) |
| Peak Hour | 12:00 PM (267 orders) |
| Peak Day | Friday ($1,895) |
| Workday Share | 70.7% of revenue |
| Top Item | Big Mac ($1,456) |
| Worst Item | Apple Slices ($19) |

## 💡 Business Insights
- **Burgers dominate** at 40.3% of total revenue — highest category by far
- **Lunch + Dinner rush** (12–13h & 17–18h) account for 46.9% of all orders
- **Workday revenue** ($8,097) is 2.4x higher than weekend ($3,356)
- **Top 5 items** generate 44.9% of revenue — high concentration risk
- **Apple Slices** earned only $19 — strong case for menu rationalisation

## 🛠️ Tools & Techniques
- **Microsoft Excel** — Data cleaning, Pivot Tables, Dashboard Design
- **Power Pivot** — Data modelling, table relationships
- **DAX Measures** — Custom KPI calculations
- **Slicers** — Interactive filtering by category, day, hour, item
- **PowerPoint** — Executive presentation and data storytelling
